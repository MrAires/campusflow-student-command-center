## Project summary

CampusFlow is a responsive web application built with ReactJS, HTML, CSS and JavaScript. It uses NodeJS and ExpressJS for RESTful backend services and MongoDB for storing student accounts, course information and assignment records. The application provides authenticated course/task CRUD, a Kanban board, deadlines, dashboard statistics, study-focus timer, progress analytics and light/dark themes.

## Tech stack

Frontend: ReactJS + HTML5 + CSS3 + JavaScript + Vite  
Backend: NodeJS + ExpressJS REST API  
Database: MongoDB  
Version control: Git and GitHub  
Deployment: Vercel + MongoDB Atlas

## Functional demo checkpoints

1. Open the website and create a student account.
2. Add a course and a new assignment.
3. Edit, complete and delete assignments using the Kanban board.
4. Update and delete a course, then view progress in Insights.
5. Verify database persistence by logging out and back in.
6. Show the responsive layout in mobile width and dark theme.

## API operations demonstrated

- Task create / read / update / delete: POST /api/tasks, GET /api/tasks, PATCH /api/tasks/:id, DELETE /api/tasks/:id
- Course create / read / update / delete: POST /api/courses, GET /api/courses, PATCH /api/courses/:id, DELETE /api/courses/:id
